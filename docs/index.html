What this resource is for

Start with data concepts, not jargon.

The first two modules focus on core ideas such as rows, columns, files, summaries, grouping, and visualisation. The examples come from sport, but the lessons are written for a broad audience.

What you will do

Build confidence with small, useful wins.

Open and inspect a dataset

Summarise and compare

Group observations into tables that a coach, analyst, or practitioner could actually use.

Save a chart and interpret it

Produce a basic visual and explain what it does and does not tell you.
