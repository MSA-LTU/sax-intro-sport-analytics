Quick start.

Use this page before starting module 1 if GitHub Classroom or Python feels new.

1. Sign in to GitHub

Create a GitHub account if you do not have one already, or sign in with your existing account.

Screenshot placeholder: GitHub sign-in or create-account screen.

2. Accept the assignment link

After registration, you will receive the GitHub Classroom link for the module. Accept the assignment to create your own private repository.

Screenshot placeholder: GitHub Classroom assignment acceptance screen.

3. Open the repository

You can work in GitHub Codespaces if it is available, or clone the repository and work locally.

Screenshot placeholder: repository page with Code and VS Code/Codespaces entry points.

4. Follow the learning path inside the repo

  1. Open quick-start.md if the repo includes it.
  2. Read lesson.md.
  3. Read assignment.md.
  4. Edit student/analysis.py.
  5. Complete reflection.md after your tests pass.

5. Run the tests

Use the terminal in Codespaces or your local environment and run:

pytest -q

The tests help you check whether your functions produce the expected outputs.

Screenshot placeholder: terminal with a passing pytest run.

6. If you get stuck

  • Read the test failure message carefully.
  • Check that column names and file names match exactly.
  • Go back to the lesson and assignment steps one function at a time.
  • Use the official references linked in the lesson sidebars if you want a deeper explanation.
