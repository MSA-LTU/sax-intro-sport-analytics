Before Module 1

Quick start checklist.

Use this when GitHub Classroom, VS Code, or Python feels new. Each step moves you closer to a working module repo.

1

GitHub account

Create a free GitHub account or sign in with your existing account.

2

Accept assignment

Use the Module 1 link from the registration confirmation to create your private repository.

3

Open repo

Work in GitHub Codespaces if available, or clone the repository and open it in VS Code.

4

Read lesson

Start with lesson.md, then use assignment.md as the task brief.

5

Run tests

Use pytest -q to check your work as you complete student/analysis.py.

6

Reflect

Complete reflection.md to explain what the output means in plain sport analytics language.
